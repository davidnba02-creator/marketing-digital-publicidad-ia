# Landing page para GitHub Pages

## Archivos incluidos
- `index.html`
- `styles.css`
- `script.js`
- `assets/logo-uptc-placeholder.svg`
- `assets/logo-cenes-placeholder.svg`

## Cómo publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta a la raíz del repositorio.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda los cambios y espera la publicación.

## Personalización pendiente
- Reemplaza los dos SVG de `assets/` por los logos oficiales manteniendo los mismos nombres, o actualiza las rutas en `index.html`.
- Cuando tengas las fotografías institucionales, puedes agregarlas en la sección hero o en una nueva franja visual.
- Cambia el botón de contacto por el enlace de inscripción cuando esté disponible.
- Actualiza fechas y horario en la tarjeta de información general.
